# Изменения

## v1.1.0 — 2026-11-19

Проверка живости узлов по-настоящему — ICMP больше не критерий отбора.

- Отбор по реальному прокси-хендшейку через Clash API Podkop. Причина: заблокированный сервер пингуется (и даже выигрывает по RTT), но трафик не пускает — блокировка на уровне TLS/SNI, TCP-коннект тоже проходит.
- ICMP-задержка осталась только для порядка кандидатов; за прогон проверяется до 40 серверов.
- Узлы, добавленные вручную (не из подписки), больше не удаляются при обновлении.
- Если ни один кандидат не поднялся, возвращается прежний список — дом не остаётся без туннеля.
- Поддержаны подписки с `hysteria2://`-ссылками.
- Прогон занимает около двух минут (два перезапуска Podkop).
- Исправлено: busybox `sort` не поддерживает `-o` — сортировка переписана на перенаправление.

## v1.0.0 — 2026-11-15

Первый публичный релиз.

- Страница в LuCI: URL подписки, число узлов, минимум ссылок, включение/выключение, кнопка «Обновить сейчас», строка последнего запуска.
- Скрипт обновления: отбор серверов по ping, стабильный список (живые узлы сохраняются), защита от пустой подписки.
- Поддержка подписок в открытом виде и в base64.
- Понятная ошибка для зашифрованных ссылок `happ://crypt…`.
- Режим `--check`: проверить подписку, ничего не меняя.
- Установка одной командой, удаление, cron каждые 6 часов.
